Is EDN a real contender against TOON and JSON as an LLM data format?

As a readable format, yes: Claude models answer questions about EDN data as accurately as about compact JSON. As a token-saving format, no: EDN usually costs more tokens than compact JSON, and TOON still wins uniform tables. Small models also write EDN more reliably than TOON.
